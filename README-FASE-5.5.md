# Oferta Radar — Fase 5.5: Coleta seletiva

## Fluxo novo
Meta Ads Library → extensão mostra anúncios desta tela → você seleciona → Enviar selecionados ao Radar → Caixa de Entrada no dashboard.

## Extensão
- não tenta esconder/reordenar anúncios da Meta;
- não envia tudo automaticamente;
- lista até os anúncios atualmente carregados;
- Top 10 seleciona rapidamente os melhores sinais;
- Localizar anúncio rola até o card;
- Enviar selecionados salva somente os escolhidos no storage local da extensão.

## Dashboard
Nova aba `Caixa de Entrada`:
- recebe os anúncios selecionados;
- mostra anunciante, palavra pesquisada, score, dias ativos, variações, mídias, texto, destino e sinais técnicos;
- permite voltar à Meta, abrir destino e remover da fila.

## Atualização
Esta fase altera EXTENSÃO e DASHBOARD.
1. Atualize os arquivos do projeto no GitHub/Vercel.
2. Reinstale/recarregue a pasta `meta-captor-extension` no Chrome.
3. Atualize o dashboard e a Meta Ads Library.
