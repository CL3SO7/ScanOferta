# Oferta Radar — Fase 5.6

## 1. Dossiê Automático
Na Caixa de Entrada, `Investigar` analisa a landing selecionada e salva localmente:
- headline, descrição e CTAs
- preços detectados
- checkout
- VSL/vídeo
- WhatsApp e mensagem pré-preenchida
- Meta Pixel, Analytics e UTMs
- estrutura provável do funil
- score técnico + contexto do anúncio Meta

## 2. Oportunidades & Palavras
Nova aba para encontrar termos de mineração:
- banco de palavras comerciais
- categorias (oferta, urgência, VSL, produto físico, dor etc.)
- calendário/sazonalidade
- destaque para termos em janela sazonal atual
- atalhos diretos para pesquisar cada termo na Meta Ads Library
- atalhos para comparar no Google Trends Brasil
- feed ao vivo de tendências brasileiras via endpoint público do Google Trends

Importante: o score de palavra-chave é um score interno de utilidade para mineração, NÃO volume de buscas. Google Trends é usado para validar interesse e sazonalidade.
