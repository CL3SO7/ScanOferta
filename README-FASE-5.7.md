# Oferta Radar — Fase 5.7: Inteligência de Oportunidades

## Mudança principal
A antiga lista ampla de tendências virou uma tela orientada a oportunidade comercial.

### Oportunidades
- cards de sazonalidade e evergreen
- score interno de prioridade
- momento: pesquisar / testar / planejar
- justificativa comercial
- palavras sugeridas
- botão para minerar diretamente na Meta
- Google Trends para validação
- favoritos/acompanhamento local

### Filtro de ruído
O feed ao vivo do Google Trends é filtrado para remover/rebaixar assuntos como futebol, política, celebridades, acidentes e notícias sem sinal comercial. Se nada passar, a tela fica vazia em vez de inventar relevância.

### Palavras descobertas
O sistema lê as copies dos anúncios enviados para a Caixa de Entrada e encontra frases de 2–4 palavras que se repetem. Isso cria um banco de palavras baseado no seu próprio processo de mineração.

Observação: scores são heurísticas de priorização, não faturamento, ROAS ou volume de busca.
