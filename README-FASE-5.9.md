# Oferta Radar — Fase 5.9: Mercado Validado

Nova aba `Mercado Validado`.

## Validadas observadas
Agrupa anúncios por operação/domínio e calcula evidência com:
- longevidade;
- quantidade de capturas;
- variações Meta;
- diversidade de mídias;
- reaparecimento em palavras diferentes;
- checkout;
- vídeo/VSL;
- dados do dossiê quando disponíveis.

Categorias:
- Validação forte (80+)
- Promissora (60–79)
- Em observação (40–59)
- Evidência insuficiente (<40)

Importante: isso NÃO afirma faturamento, ROAS ou quantidade de vendas. Meta Ads Library não publica esses dados para anúncios comerciais. O score mede evidência observável de continuidade/escala.

## Descobrir infoprodutos
Catálogo de arquétipos escaláveis para mineração:
- ferramentas práticas;
- planilhas/templates;
- idiomas;
- carreira/concursos;
- hobbies monetizáveis;
- produtividade;
- desenvolvimento pessoal;
- fitness/bem-estar não médico.

Cada arquétipo tem termos prontos para pesquisar na Meta e atalho para Google Trends.

A extensão 5.8 continua compatível.
