# Oferta Radar — Fase 6.2: Mapa de Dores & Soluções

Nova página `🧠 Dores & Soluções`.

Fluxo:
dor -> resultado desejado -> soluções vendáveis -> formato recomendado -> pesquisas de validação -> Meta -> Motor de Descoberta.

Recursos:
- entrada por público/nicho/problema;
- mapas especializados para manicures, pequenos negócios, inglês, concursos, culinária/confeitaria, beleza, pets e organização/finanças;
- fallback para nichos não catalogados;
- score de potencial de investigação;
- resultado que a pessoa realmente quer;
- múltiplas soluções possíveis, sem assumir ebook;
- recomendação de ferramenta/software/programa/kit conforme natureza da dor;
- pesquisas prontas na Meta;
- Google Trends;
- integração conceitual com o Motor de Descoberta 6.1.

O score é heurístico, não representa vendas, faturamento ou volume de busca.

Nesta fase apenas o dashboard mudou. A extensão 6.1 continua compatível.
